About

Learn more about this project

This project was inspired by Queering the Map by Lucas Roche, a beautiful project that explores the intersection of identity and space.

This stylised map acts as a missed connections board, a memory map, a place to put undelivered gratitude, follow up on almost-friendship, and moments of recognition. Inspired by mixed passions for creative cartography, web design and community impact, the developer hopes this project allows for fleeting moments to etch deeper, and for kindness to be shared in a new way.

Developed by Hannah Ashe, using Django and Maplibre GL.
